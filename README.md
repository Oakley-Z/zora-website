# Zora 个人网站

基于 `Zora_个人网站_产品需求文档_PRD.pdf` 制作的首版静态个人品牌网站。

## 内容范围

- Home：个人品牌第一屏，突出 `Product x AI x Design`
- Projects：以项目作为能力证明，包含个人网站、极简记账、知识库、穿搭收藏系统
- About：用产品叙事组织个人介绍、当前阶段与真实经历
- Skills：Product / AI / Design / Content 能力结构
- Picks：展示个人审美、兴趣和工具使用
- Contact：以邮箱作为主要转化入口

## 交互范围

- 简体中文 / 繁体中文 / English 三语言切换
- 根据浏览器语言和时区自动选择默认语言
- 项目卡片悬停反馈
- 滚动显现动效
- Curated Picks 内容切换
- 邮箱复制

## 本地预览

在本目录启动静态服务后访问：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173`。
